# 🪙 ربات هوشمند مدیریت سبد دارایی طلا، سکه، نقره، ارز و محاسبه سود/زیان (TGJU Portfolio Tracker)

ربات تلگرامی پیشرفته با اتصال زنده به شبکه اطلاع‌رسانی طلا و ارز (`TGJU.org`) برای ثبت، مدیریت و محاسبه لحظه‌ای ارزش روز و **میزان سود و زیان (P&L)** دارایی‌های طلا، سکه، نقره و ارزها.

---

## 📈 محاسبه هوشمند سود و زیان (P&L Engine)

هنگام ثبت هر دارایی، ربات در مرحله دوم **میانگین قیمت خرید (به تومان)** را از شما می‌پرسد:
- **محاسبه خودکار ارزش روز بازار:** `تعداد / وزن × نرخ زنده TGJU`
- **محاسبه کل مبلغ خرید (سرمایه‌گذاری):** `تعداد / وزن × بهای خرید`
- **محاسبه سود / زیان هر قلم:** نمایش سود (`🟢 +تومان (+درصد)`) یا زیان (`🔴 -تومان (-درصد)`)
- **خلاصه عملکرد کل سبد:** نمایش مجموع سود خالص و درصد بازدهی کل سرمایه‌گذاری شما
