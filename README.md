## 💎 ویژگی‌ها و قابلیت‌های اصلی سامانه

### ۱. انطباق ۱۰۰٪ با نرخ‌های زنده شبکه اطلاع‌رسانی طلا و ارز (`TGJU.org`)
تمام قیمت‌ها و اطلاعات آماری بازار به طور مستقیم و بدون دخالت دستی از شبکه `TGJU.org` استخراج و بروزرسانی می‌شوند:
- **طلا و آبشده:** طلای ۱۸ عیار، طلای ۲۴ عیار، طلای دست دوم (بدون اجرت)، مثقال طلا و آبشده نقدی
- **سکه و حباب:** تمام سکه امامی، بهار آزادی، نیم سکه، ربع سکه، سکه گرمی، سکه‌های طرح قدیم (قبل از ۱۳۸۶) و محاسبه حباب واقعی هر سکه
- **نقره فیزیکی:** نقره ۹۹۹ خالص (شمش و ساچمه)، نقره ۹۲۵ استرلینگ
- **ارزهای آزاد:** دلار آمریکا، تتر (`USDT`)، یورو، درهم امارات، پوند، لیر، دلار کانادا و استرالیا، ۱۰۰ دینار عراق
- **سکه‌های پارسیان:** جدول کامل ۱۵ وزن پارسیان (از ۱۰۰ سوت تا ۱.۵ گرم)

---

### ۲. تابلوی جامع سقف و کف روزانه و دامنه نوسان
- نمایش لحظه‌ای قیمت فعلی، بالاترین و پایین‌ترین قیمت ثبت‌شده امروز (`Daily High/Low`)
- درصد و مبلغ نوسان هر قلم دارایی به همراه برچسب زمانی آخرین تغییر
- دسته‌بندی و فیلترهای تفکیکی بر اساس طلا، نقره، سکه جدید، سکه قدیم، پارسیان، ارزها و حباب‌ها
- جستجوی سریع دارایی‌ها

---

### ۳. مدیریت حرفه‌ای سبد سرمایه‌گذاری و سود/زیان (P&L Tracker)
- **ثبت دارایی‌های متنوع:** طلا، مسکوکات، نقره، پارسیان و ارزها
- **محاسبه هوشمند P&L:** محاسبه هم‌زمان ارزش روز بر اساس آخرین نرخ زنده TGJU، محاسبه بهای تمام‌شده و درصد سود/زیان
- **استقلال کامل و حریم خصوصی:** عملکرد ۱۰۰٪ کلاینت‌ساید (بدون نیاز به سرور واسط یا پایگاه داده ابری) با ذخیره‌سازی ایمن روی مرورگر کاربر (`LocalStorage`)

---

### ۴. سناریوساز و دستیار هوشمند تخصیص دارایی (Asset Allocation Advisor)
- پیشنهاد سبد بهینه بر اساس بودجه ریالی با استراتژی میانگین کم‌کردن چندپله‌ای (`DCA`)
- تحلیل نسبت برابری طلا به نقره (`Gold/Silver Ratio - GSR`)
- ارزیابی شدت حباب مسکوکات جهت جلوگیری از خرید در اوج هیجان

---

### ۵. بهینه‌سازی کامل رابط کاربری موبایل و دسکتاپ
- منوی کناری کشویی (Collapsible Responsive Drawer) مناسب انواع تبلت‌ها و گوشی‌های هوشمند
- سازگاری کامل با جهت‌گیری راست‌به‌چپ (`RTL`) و ارقام استاندارد فارسی
- پشتیبانی از تم تاریک (`Dark Mode`) و روشن (`Light Mode`)

## 🛠 نحوه راه‌اندازی و اجرا روی سیستم شخصی

### اجرای نسخه تحت وب (Static Web Server):
```bash
# رفتن به پوشه پروژه و اجرای سرور لوکال
python -m http.server 8080
```
سپس مرورگر خود را باز کرده و به آدرس `http://localhost:8080/` بروید.

### اجرای ربات تلگرام (در صورت تمایل به استفاده از نسخه بات):
```bash
# نصب پیش‌نیازها
pip install -r requirements.txt

# تنظیم توکن در فایل .env
# BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN_HERE

# اجرای ربات
python main.py
```
