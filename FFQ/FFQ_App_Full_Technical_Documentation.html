۱. معماری کلان نرم‌افزار و دلایل انتخاب ابزارها

پروژه بر پایه متدولوژی مدرن Single Activity Declarative UI پایه‌ریزی شده است. در برنامه‌نویسی سنتی اندروید، چندین اکتیویتی یا فرگمنت با فایل‌های چیدمان پیچیده XML و کدهای سنگین بایندینگ ایجاد می‌شد که مصرف حافظه بسیار بالایی داشت و در انتقال داده‌ها میان مراحل پرسشنامه، با ارورهای معروفی مانند TransactionTooLargeException یا گم شدن وضعیت (State Loss) مواجه می‌گردید.

رویکرد پیاده‌سازی شده در این اپلیکیشن: کل برنامه تنها دارای یک اکتیویتی واحد (MainActivity) است. وضعیت صفحات به صورت یک State Machine امن با کلاس مهر و موم‌شده (Sealed Class Screen) مدیریت می‌شود. داده‌ها به صورت Immutable State در حافظه نگهداری شده و با ترنزیشن نرم Crossfade کاربر میان مراحل پرسشنامه جابجا می‌شود.

عدم وابستگی به اینترنت و سرویس‌های خارجی: به دلیل حساسیت داده‌های سلامت بیماران، کلیه پردازش‌های بیومتریک، محاسبات فرکانس و تولید فایل‌های اکسل در پردازنده دستگاه کلاینت (روی خود گوشی) به صورت آفلاین اجرا می‌شود.

تحلیل ماشین وضعیت در AppNavigator.kt

این کامپوننت هسته هدایت کاربر است. سه وظیفه مهندسی را اجرا می‌کند:

  1. اعمال چیدمان راست به چپ عمومی: با استفاده از CompositionLocalProvider(LocalLayoutDirection provides LayoutDirection.Rtl) کل برنامه بدون نیاز به تگ‌های متفرقه در تمام گوشی‌ها به صورت فارسی استاندارد رندر می‌شود.
  2. مدیریت دکمه فیزیکی بازگشت (BackHandler): با زدن دکمه بازگشت در منوی اصلی، با پیاده‌سازی تایمر کوئری ۲ ثانیه‌ای (delay(2000)) پیام «برای خروج مجدداً دکمه بازگشت را بزنید» نمایش داده می‌شود تا کاربر تصادفاً از برنامه خارج نشود.
  3. انتقال داده‌ها بدون گم‌شدگی (Safe State Propagation): ارسال مشخصات بیمار از ثبت‌نام به پرسشنامه بسامد و هدایت به صفحه جزئیات بیمار پس از ذخیره موفق.
AppNavigator.kt Kotlin 
@Composable
fun AppNavigator(themeMode: String = "light", onThemeModeChanged: (String) -> Unit = {}) {
    var currentScreen: Screen by remember { mutableStateOf(Screen.Splash) }
    val context = LocalContext.current
    val scope = rememberCoroutineScope()
    var backPressedOnce by remember { mutableStateOf(false) }

    CompositionLocalProvider(
        LocalLayoutDirection provides LayoutDirection.Rtl,
        LocalAppStrings provides AppStrings()
    ) {
        BackHandler {
            when (currentScreen) {
                is Screen.Splash -> { }
                is Screen.Login -> (context as? Activity)?.finish()
                is Screen.MainMenu -> {
                    if (backPressedOnce) (context as? Activity)?.finish()
                    else {
                        backPressedOnce = true
                        Toast.makeText(context, "برای خروج مجدداً بازگشت را بزنید", Toast.LENGTH_SHORT).show()
                        scope.launch { delay(2000); backPressedOnce = false }
                    }
                }
                is Screen.Registration -> currentScreen = Screen.MainMenu
                is Screen.FFQQuestionnaire -> currentScreen = Screen.MainMenu
                is Screen.PatientDetail -> currentScreen = Screen.History
                else -> currentScreen = Screen.MainMenu
            }
        }

        Crossfade(targetState = currentScreen, animationSpec = tween(400)) { screen ->
            when (screen) {
                is Screen.Splash -> SplashScreen(onFinished = { currentScreen = Screen.Login })
                is Screen.Login -> LoginScreen(...)
                is Screen.Registration -> RegistrationScreen(...)
                is Screen.FFQQuestionnaire -> FFQQuestionnaireScreen(...)
                is Screen.PatientDetail -> PatientDetailScreen(...)
                is Screen.History -> HistoryScreen(...)
            }
        }
    }
}

۳. مدیریت نشست و کاربران در لایه دیسک (AppPrefs.kt)

برای مدیریت لیست پرسنل درمانگاهی، احراز هویت ورود و ذخیره تم برنامه، از کلاس کاتلین AppPrefs با دسترسی Context.MODE_PRIVATE استفاده شده است. لیست کاربران به عنوان یک آرایه از جفت مقادیر نام کاربری و پسورد با Gson سریالایز و ذخیره می‌شود:

AppPrefs.kt Kotlin 
object AppPrefs {
    private const val PREFS_NAME = "FFQPrefs"
    private fun getPrefs(context: Context) = context.getSharedPreferences(PREFS_NAME, Context.MODE_PRIVATE)

    fun getUsers(context: Context): List<Pair<String, String>> {
        val json = getPrefs(context).getString("allowed_users", null)
        if (json == null) {
            // کاربر اولیه پیش‌فرض سیستم
            val initial = listOf("user" to "1234")
            saveUsers(context, initial)
            return initial
        }
        val type = object : TypeToken<List<Pair<String, String>>>() {}.type
        return try { Gson().fromJson(json, type) ?: emptyList() } catch (e: Exception) { emptyList() }
    }

    fun setThemeMode(context: Context, mode: String) {
        getPrefs(context).edit { putString("app_theme_mode", mode) }
    }
}

data class RegistrationData(
    val id: String = "",
    val diagnosisMO: String = "",
    val marital: Int? = null,
    val otherNarcotics: String = "",
    val ghelian: String = "",
    val cigar: String = "",
    val aspirin: Int? = null,
    val levotyroxin: Int? = null,
    val statin: String = "",
    val vitD: Int? = null,
    val multivitamin: Int? = null,
    val diabetes: Int? = null,
    val cvd: Int? = null,
    val bp: Int? = null,
    val migrane: Int? = null,
    val gid: Int? = null,
    val cancer: Int? = null,
    val weightKg: String = "",
    val heightCm: String = "",
    val gender: Int? = null,
    val age: String = "",
    val education: Int? = null,
    val job: Int? = null,
    val familySize: String = "",
    val kids: String = "",
    val houseOwnership: Int? = null,
    val ipaq: Map<Int, String> = emptyMap(),
    val timestamp: Long = System.currentTimeMillis()
) {
    // محاسبه تنبل BMI با بررسی دقیق معتبر بودن قد و وزن
    val bmi: Double? get() {
        val w = weightKg.toDoubleOrNull() ?: return null
        val h = heightCm.toDoubleOrNull() ?: return null
        if (h <= 0) return null
        val hm = h / 100.0
        return w / (hm * hm)
    }

    // محاسبه نمره متابولیک کل IPAQMET با ۱۲ زوج سوال
    val ipaqMet: Double get() {
        fun pair(p1: Int, p2: Int, factor: Double): Double {
            val v1 = ipaq[p1]?.toDoubleOrNull() ?: 0.0
            val v2 = ipaq[p2]?.toDoubleOrNull() ?: 0.0
            return v1 * v2 * factor
        }
        return pair(2, 3, 8.0) + pair(4, 5, 4.0) + pair(6, 7, 3.3) +
               pair(8, 9, 0.0) + pair(10, 11, 4.0) + pair(12, 13, 3.3) +
               pair(14, 15, 8.0) + pair(16, 17, 4.0) + pair(18, 19, 3.3) +
               pair(20, 21, 3.3) + pair(22, 23, 8.0) + pair(24, 25, 4.0)
    }
}

ب) کلاس مدل پاسخ‌های خوراک و نرخ معادل مصرف روزانه

زمانی که کاربر فرکانس مصرف را در یکی از کادرها وارد می‌کند، متد toDailyMultiplier() برای تبدیل نرخ مصرف به مبنای روزانه وارد عمل می‌شود:

FFQModels.kt Kotlin 
data class FFQAnswer(
    val day: String = "",
    val week: String = "",
    val month: String = "",
    val year: String = "",
    val userNotes: String = "" // ملاحظات اختصاصی بیمار
) {
    fun isEmpty(): Boolean = day.isBlank() && week.isBlank() && month.isBlank() && year.isBlank() && userNotes.isBlank()

    // نرخ معادل دریافت روزانه
    fun toDailyMultiplier(): Double {
        val d = day.toDoubleOrNull()
        if (d != null && d > 0) return d
        val w = week.toDoubleOrNull()
        if (w != null && w > 0) return w / 7.0
        val m = month.toDoubleOrNull()
        if (m != null && m > 0) return m / 30.42
        val y = year.toDoubleOrNull()
        if (y != null && y > 0) return y / 365.0
        return 0.0
    }
}

۵. الگوریتم ضرب ماتریسی ۶۲ ریزمغذی

در فایل‌های PatientDetailScreen.kt و ExcelExporter.kt، دریافت واقعی هر یک از مواد مغذی با یک الگوریتم ماتریسی با پیچیدگی زمانی خطی $O(N imes M)$ محاسبه می‌گردد. در این حلقه، هر ماده غذایی ابتدا به نرخ مصرف روزانه تبدیل شده، سپس در جدول فاکتورهای غذایی ضرب و در یک هش‌مپ تجمیع می‌شود:

PatientDetailScreen.kt Kotlin 
// محاسبه زنده ۶۲ ریزمغذی در زمان بارگذاری پرونده
val nutrientTotals = remember(currentRecord, allItems) {
    val totals = mutableMapOf<String, Double>()
    for (item in allItems) {
        val ans = answers[item.id] ?: continue
        val mult = ans.toDailyMultiplier()
        if (mult <= 0) continue

        // ضرب در فاکتورهای جدول Nutrients Forme
        for ((k, v) in item.nutrients) {
            totals[k] = (totals[k] ?: 0.0) + (mult * v)
        }
    }
    totals
}

نام شاخص تغذیه‌ای واحد سنجش نحوه محاسبه

پروتئین کل (protein) گرم (g) تجمیع پروتئین حیوانی و گیاهی

// تابع فیلد سال
FrequencyInput(
    label = "سال",
    value = answer.year,
    modifier = Modifier.weight(1f)
) { input ->
    if (input.isBlank()) {
        onAnswerChange(FFQAnswer(userNotes = answer.userNotes))
    } else {
        val y = input.toDoubleOrNull()
        if (y != null && y >= 0) {
            val m = formatFreq(y / 12.0)
            val w = formatFreq(y / 52.14)
            val d = formatFreq(y / 365.0)
            onAnswerChange(
                FFQAnswer(day = d, week = w, month = m, year = input, userNotes = answer.userNotes)
            )
        } else {
            onAnswerChange(answer.copy(year = input))
        }
    }
}

۷. فرم جامع ثبت‌نام ۵۲ ستونه و ۶ آکاردئون

در فایل RegistrationScreen.kt، به دلیل حجم بالای ۵۲ فیلد اکسل مرجع، فرم در قالب ۶ بخش بازشونده (Accordion) سازماندهی شده است:

  • بخش ۱: مشخصات هویتی و دموگرافیک (شناسه، سن، جنسیت، وضعیت تاهل، تحصیلات، شغل، بعد خانوار، تعداد فرزندان، مسکن)
  • بخش ۲: شاخص‌های آنتروپومتری (وزن، قد و دور کمر به همراه محاسبه زنده و تغییر رنگ خودکار کارت BMI)
  • بخش ۳: عادات و مصرف دخانیات (سیگار، قلیان و سایر مخدرها)
  • بخش ۴: داروها و مکمل‌های مصرفی (آسپرین، لووتیروکسین، استاتین، ویتامین دی، مولتی‌ویتامین)
  • بخش ۵: سوابق بیماری‌های مزمن (دیابت نوع ۱ و ۲، فشار خون، بیماری‌های قلبی، میگرن، سرطان، گوارش)
  • بخش ۶: پرسشنامه بین‌المللی فعالیت بدنی (IPAQ 2 تا 25) با رندر برداری و محاسبه زنده نمره متابولیک کل.

private fun getColName(colIdx: Int): String {
    var col = colIdx
    val sb = StringBuilder()
    while (col > 0) {
        val rem = (col - 1) % 26
        sb.append(('A'.code + rem).toChar())
        col = (col - 1) / 26
    }
    return sb.reverse().toString()
}

fun WindowsXpProgressBar(modifier: Modifier = Modifier) {
    val transition = rememberInfiniteTransition(label = "xp_loader")
    val animProgress by transition.animateFloat(
        initialValue = -0.35f,
        targetValue = 1.35f,
        animationSpec = infiniteRepeatable(
            animation = tween(1250, easing = LinearEasing),
            repeatMode = RepeatMode.Restart
        ),
        label = "xp_progress"
    )

    Box(
        modifier = modifier
            .width(176.dp)
            .height(15.dp)
            .clip(RoundedCornerShape(3.dp))
            .background(Color.Black)
            .border(1.5.dp, Color(0xFF4A4E46), RoundedCornerShape(3.dp))
            .clipToBounds()
    ) {
        BoxWithConstraints(modifier = Modifier.fillMaxSize()) {

object FFQRepository {
    private var cachedItems: List<FFQItem>? = null

    fun loadFFQItems(context: Context): List<FFQItem> {
        cachedItems?.let { return it }
        return try {
            val jsonString = context.assets.open("ffq_database.json").bufferedReader().use { it.readText() }
            val type = object : TypeToken<List<Map<String, Any>>>() {}.type
            val rawList: List<Map<String, Any>> = Gson().fromJson(jsonString, type)
            val list = rawList.map { m ->
                // پارس کردن ایمن شناسه‌ها، اسامی و مپ مقادیر ریزمغذی
                FFQItem(...)
            }.sortedBy { it.id }
            cachedItems = list
            list
        } catch (e: Exception) { emptyList() }
    }
}
